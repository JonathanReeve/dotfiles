* Foundational System Configuration & Notetaking Standards

I use /NixOS/ and /Home Manager/ with ~nix-doom-emacs-unstraightened~. All configuration lives in ~/Agordoj/dotfiles/~.

** Notetaking (Vulpea & Zettelkasten)
- *Directory*: All notes live in ~/Dokumentoj/Org/Roam/~.
- *Database*: We use /Vulpea/ for node management.
  - ~vulpea-db-sync-directories~ includes both the Roam folder and the base Org directory.
  - ~SPC n r f~ is bound to ~vulpea-find~ (node search) with ~consult-vulpea-mode~ for live previews.
  - Hierarchy display is enabled via ~vulpea-select-describe-outline-full~.
- *Formatting*: We strictly use /file-level metadata/ in the top-level property drawer. Internal "title headings" (e.g., ~* Mrs Dalloway~) are forbidden and should be promoted to the file level.

** Bibliographic Integration (Citar)
- *Database-First*: ~citar-bibliography~ is set to ~vulpea.db~. We treat Org notes as the canonical source for bibliographic metadata.
- *Custom Citar Fork*: We use a local fork at ~/Programaroj/citar/~ that is patched to:
  - Detect Vulpea databases.
  - Parse JSON properties directly from the ~notes~ table.
  - Discover citekeys from the ~:REFERENCES:~ or ~:CUSTOM_ID:~ properties.
- *Metadata Standards*: We use the standard /org-bibtex/ property names in uppercase:
  - ~:CUSTOM_ID:~ - The BibTeX citekey.
  - ~:REFERENCES:~ - Vulpea association (format: ~cite:KEY~).
  - ~:AUTHOR:~, ~:YEAR:~, ~:URL:~, ~:PUBLISHER:~, etc.
- *Capture*: ~SPC X b~ is bound to a literature note capture that redirects to ~vulpea-capture~.

** Automation & Tools
- *Shell*: We prefer /Nushell/ (~nu~) for all scripts and agent tools. Never use Bash for agent tasks.
- *Metadata Enhancement*: Use ~scripts/enhance-bib-metadata.el~ (bound to ~SPC n r e~) to fill missing metadata via CrossRef (DOI) or Google Books.
- *Visualizations*: ~scripts/visualize_habits.py~ generates interactive Plotly charts for journal stats and habits.
- *Browser Integration*: Qutebrowser userscripts in ~scripts/qutebrowser-userscripts/~:
  - ~gV~ (~vulpea-bookmark~): Captures page + selection as a Vulpea note.
  - ~gW~ (~wikidata-movie~): Captures movie metadata from Wikidata to ~movies.org~.

** AI (GPTel)
- *Model*: Default to ~gemini-1.5-flash~ (preview 2.0-flash has zero quota for free users).
- *Credentials*: Handled via ~auth-source-pass~ from ~/home/jon/Dokumentoj/Personal/.password-store~.
- *Agents*: Custom agent definitions live in ~/Agordoj/agents/~.
